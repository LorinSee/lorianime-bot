# Anime Bot

Telegram-бот, который показывает случайное аниме, ищет по названию и показывает описания. Использует API Shikimori.

## Стек
- Python 3.12
- aiogram 3.x
- aiohttp
- Shikimori API

## Возможности
- Случайное аниме с картинкой
- Описание аниме
- Поиск по названию 

## Установка
1. Клонируй репозиторий
2. Установи зависимости: `pip install -r requirements.txt`
3. Создай `.env` на основе `.env.example` и вставь свой токен
4. Запусти: `python main.py`
